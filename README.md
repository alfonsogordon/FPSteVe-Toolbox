# FPSteVe Toolbox

A lightweight, mobile-friendly GitHub Pages hub for my own FPV web apps and projects.

## Publish

In repository **Settings → Pages**, select **Deploy from a branch**, branch **main**, folder **/(root)**, then Save.

Once published, the expected address is https://alfonsogordon.github.io/FPSteVe-Toolbox/

## Included

- FPV CamBuddy
- Betaflight Throttle Converter
- Blackbox Stick Overlay

Squadding Quads Overlays and third-party tools are intentionally excluded.

## Editing

Update the `apps` array in `index.html`. Add a verified live URL in `site` to display an **Open web app** button; leave it `null` until confirmed.
