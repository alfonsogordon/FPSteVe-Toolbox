HelloRadioSky V12 Max · EdgeTX · custom RGB button lighting

Project guide · script download pending

Our custom lighting project

Throttle-reactive RGB effects for the six customizable switches, with stick-based colour movement and multiple palette styles.

  • JET and SCROLL stick/throttle animation
  • Six RGB switch buttons: SW1–SW6
  • RGB palettes including JET, CYBER, PLASMA, SYNTH, FIRE and TRON from earlier versions
  • Roll-driven gradient shift and pitch tint explored in the project

Script versions

RGBSTKS.lua — later function-script version, designed to preserve JET/SCROLL animations and control switch LEDs using setCFSLedColor.

BTTEST6.lua — earlier full-screen tool test using the customizable switch LED API.

The final Lua file itself has not yet been recovered and verified, so this page deliberately does not offer an untested download.

Installation notes

For the later function-script version, the intended location is /SCRIPTS/FUNCTIONS/RGBSTKS.lua on the radio SD card. The BTTEST6 test tool used /SCRIPTS/TOOLS/BTTEST6.lua.

Button configuration differed between tests. For the BTTEST6 setup, SW1–SW6 were configured with Lua Override enabled, and the RGBLED Special Function was disabled. Check the matching script version before applying switch settings.
